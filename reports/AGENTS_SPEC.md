# Implementation spec for agents/ (for OpenCode)
Implement the agents/ package described in reports/ARCHITECTURE.md, Python 3.12, only stdlib, pandas, numpy, requests, ccxt. Files: agents/__init__.py, common.py, market_agent.py, news_agent.py, session_agent.py, risk_agent.py, decision_agent.py, run_cycle.py.
- load_candles(pair, tf, asof) in common.py: read user_data/data/bybit/{BASE}_{QUOTE}-{tf}.feather (date tz-aware UTC); return rows with date < asof only. Timeframes 1m,5m,15m,1h,4h,1d; missing file -> None.
- market_agent.analyze(pairs, asof, live_orderbook=False): per tf: close, ema50, ema200, ema50 slope over 5 bars, pct distance to rolling-20 high and low, atr_pct(14), volume z-score(48), regime bull (close>ema200 and ema50>ema200) / bear (both below) / range. If live_orderbook: ccxt.bybit() public fetch_order_book(pair, limit=50): spread_pct, bid/ask depth within 1% of mid in USDT (try/except).
- news_agent.analyze(asof): sentiment/sentiment.sqlite tables fng(ts_utc,value,classification,source_ts), gdelt_tone(ts_utc,query,bucket_date,tone), reddit_posts(ts_utc,subreddit,post_id,title,score,num_comments,created_utc); plus user_data/external/fng.csv (date,fng; value of date D usable only from D+1 00:00 UTC) for historical asof. Return fng latest, fng 7d change, gdelt mean tone 24h vs 7d per query, reddit post count; missing -> null.
- session_agent.analyze(pairs, asof): 1h candles of 90 days before asof; mean return and mean abs return by weekday and by session (asia 00-08 UTC, london 07-16, ny 13-21); current weekday/session.
- risk_agent.analyze(asof, api_url=None): BTC 1d close vs EMA200 via load_candles; if api_url, Basic auth from config.private.json api_server.username/password, GET /profit and /status (try/except) for max_drawdown and open trades. size_cap: drawdown>0.10 -> 0; BTC below EMA200 -> 0.5; else 1.0.
- common.call_llm(prompt, timeout=300): subprocess [opencode_exe,'run','-m',model,prompt], cwd = project root, opencode_exe = shutil.which('opencode.cmd') or shutil.which('opencode'); models opencode/deepseek-v4.1-flash-free then opencode/glm-5.3-flash-free on failure/timeout. Strip ANSI codes, extract first JSON object. Return (dict|None, raw_text, model_used).
- decision_agent.decide(pairs, asof, use_llm=True, api_url=None, live_orderbook=False): gather 4 reports; prompt asks for JSON exactly {"pairs": {PAIR: {"action":"allow|block","size":0..1,"confidence":0..1,"rationale":"..."}}, "followups": ["..."]}. Up to 2 follow-up rounds answered by appending full market+session detail. Validate: missing/unknown pairs -> block size 0; size clipped to [0, size_cap]. On LLM failure or use_llm False: fallback rule allow size=size_cap only if 1h and 4h regime bull and size_cap>0 else block; record source "llm" or "fallback".
- run_cycle.py CLI (python -m agents.run_cycle): --pairs (default whitelist from user_data/config.json exchange.pair_whitelist), --asof ISO (default now UTC), --no-llm, --api-url, --live-orderbook. Write reports/decisions/YYYY-MM-DD_HHMM.json (asof-based, UTC) with inputs, prompts, raw llm text, model, decision. In live mode (no --asof) also write user_data/decisions/latest.json {asof, generated_at, source, pairs}. Print one line per pair.
